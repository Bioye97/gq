# ex04_anisotropic_correlation

This example demonstrates axis-aligned anisotropy through the correlation
lengths supplied with `-C`. Panel (a) uses the isotropic value `-C8`,
while panel (b) uses `-C20/4`, producing features that are longer along x
than y. Both fields use the same standard deviation, Hurst exponent, seed,
domain, and sampling.

Run:

```bash
./ex04_anisotropic_correlation.sh
```

The script creates `ex04_anisotropic_correlation.png` and
`ex04_anisotropic_correlation.pdf`.
