# ex07_window_functions

This example compares boxcar, linear, cosine, smoothstep, Gaussian, and
Planck-taper windows on the same four-pointed isotoxal-star support. The
non-boxcar cases use a taper ratio of 0.3, and each panel displays the tapered
heterogeneity generated from the same random realization. Dashed outlines mark
the support boundary.

Run:

```bash
./ex07_window_functions.sh
```

The script creates `ex07_window_functions.png` and
`ex07_window_functions.pdf`.
