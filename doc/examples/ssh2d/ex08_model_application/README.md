# ex08_model_application

This example applies a two-dimensional fractional heterogeneity field to a
synthetic velocity grid with `-A`. The von Karman realization has standard
deviation 0.04, anisotropic correlation lengths `10/6`, Hurst exponent
0.35, and seed 37.

The three panels show the original velocity model, the perturbed model, and
their absolute difference.

Run:

```bash
./ex08_model_application.sh
```

The script creates `ex08_model_application.png` and
`ex08_model_application.pdf`.
