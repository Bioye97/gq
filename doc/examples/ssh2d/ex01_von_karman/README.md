# ex01_von_karman

This example generates a two-dimensional von Karman fractional heterogeneity
field over `-R0/100/0/100` at a spacing of 0.5. It uses a standard deviation
of 0.05, isotropic correlation length of 8, Hurst exponent of 0.3, and random
seed 42.

Run:

```bash
./ex01_von_karman.sh
```

The script creates `ex01_von_karman.png` and `ex01_von_karman.pdf`.
