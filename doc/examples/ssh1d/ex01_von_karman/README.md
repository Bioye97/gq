# ex01_von_karman

This example generates a one-dimensional von Karman fractional heterogeneity
field over `0/100` with a spacing of 0.1. It uses a standard deviation of
0.05, correlation length of 5, Hurst exponent of 0.3, and random seed 42.

Panel (a) plots the realization and marks zero perturbation. Panel (b) shows
its power spectrum on logarithmic axes.

Run:

```bash
./ex01_von_karman.sh
```

The script creates `ex01_von_karman.png` and `ex01_von_karman.pdf`.
