# ex03_statistical_parameters

This example compares how standard deviation and Hurst exponent affect a
two-dimensional von Karman field. With a common domain, correlation length
of 8, and seed 81, the panels show standard deviations of 0.03 and 0.10
followed by Hurst exponents of 0.15 and 0.85.

All panels share one color scale so the change in amplitude from `-D` and
the change in texture from `-U` remain visually distinct.

Run:

```bash
./ex03_statistical_parameters.sh
```

The script creates `ex03_statistical_parameters.png` and
`ex03_statistical_parameters.pdf`.
